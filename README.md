# A&S WebCrafters

Agency site for [A&S WebCrafters](https://as-webcrafters.vercel.app/) — diagnosis-first layout with working navigation, FAQ, and contact form.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js App Router, Tailwind CSS v4, Framer Motion, Lucide icons. Fonts: Inter + Playfair Display.
